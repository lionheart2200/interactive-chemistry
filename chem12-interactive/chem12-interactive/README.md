# الكيمياء – الصف الثاني عشر | الكتاب التفاعلي

ملف واحد `index.html` يحتوي صفحات المذكرة (66 صفحة) + 21 مختبرًا تفاعليًا + حلول التمارين.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع `index.html` إلى الفرع `main`.
2. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `(root)`.
3. الرابط: `https://<username>.github.io/<repo>/` — ولفتح صفحة محددة أضف `#p12`.

## التعديل
- مناطق اللمعان الحمراء فوق الأشكال: الجدول `HOT` (الصفحة ← المحاكاة، الخيارات، [x٪, y٪, العرض٪, الارتفاع٪])؛ وإذا كُتب الموضع برقمين فقط [x٪, y٪] تظهر شارة «جرّب» بلا إطار.
- مواضع لمعان الحلول الأخضر فوق عناوين الأسئلة: `ANS_AT`.
- نصوص الحلول: الكائن `ANS` (مفتاحه رقم صفحة الـ PDF).
- الاسم ورقم الهاتف: الثابت `TEACHER`.
